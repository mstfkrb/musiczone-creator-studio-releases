# Musiczone Creator Studio · Sürümler

Bu depo yalnızca Musiczone Creator Studio'nun Windows kurulum dosyalarını ve sürüm notlarını içerir. Kaynak kod burada değildir.

- İndirmek için: **Releases** bölümündeki en son `MusiczoneCreatorStudio-Setup-v….exe` dosyası.
- Kurulu uygulama yeni sürümleri buradan kendisi denetler ve onayınla günceller.
- Her setup dosyasının yanında doğrulama için `.sha256` dosyası bulunur.
